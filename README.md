# Fresh Eggs Mart

Farm-fresh eggs and frozen foods in Aba — wholesale and retail SPA demo.

## Live

GitHub Pages: https://femi-wares.github.io/fresh-eggs-mart/

## Local

Open `index.html` or serve the folder statically.

Edit `WA_NUMBER` in `app.js` for WhatsApp orders.

## Stack

Vanilla HTML / CSS / JS · Hash SPA · PWA · Mobile bottom nav
